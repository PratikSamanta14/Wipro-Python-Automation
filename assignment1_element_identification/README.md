# Selenium Assignment 1 - Web Element Identification

## Assignment Objective

Identify and locate different web elements on a webpage using Selenium WebDriver with Python.

The assignment demonstrates the following Selenium locator strategies:

- By.ID
- By.NAME
- By.LINK_TEXT
